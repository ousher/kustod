04 / THE ENGINE

IDENTITATIS — for when the habit outgrows copy‑paste.

The prompt gives you a partner for one session; the two-line wrap keeps it alive as long as you keep pasting. IDENTITATIS is that loop, written down — a folder layout and two small scripts. One reads your identity and prints it. The other ends the session and writes it back.

identity.md

Who this is. Loaded first, every single time.

laws/

One file per rule — each carrying the reason it exists.

handoff.md

What happened last time. Newest on top.

boot.py · save.py

One prints the block you paste. One writes the session back.

No API calls. No keys. An identity that only survives on one vendor's runtime isn't an identity — it's a configuration file.
